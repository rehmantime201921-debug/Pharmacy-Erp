MEGA ERP - Setup

How will this computer be used? (You can open this screen again later with Ctrl+Shift+F9.)

1. Only one computerOnly this computer will use the software in this pharmacy.
2. This is the MAIN computerThe data stays on this computer. Other computers connect to it. This computer must stay switched on all day.
3. This is a SECOND computerThe data comes from the main computer. Bills, stock and accounts look exactly the same on both computers.
-
On the second computer, enter this same address and code in Setup. If Windows Firewall asks for permission, click "Yes / Allow". It is better to keep this computer's IP fixed (give this computer a fixed IP in the router).
If this computer already has old data, it will not be used - only the main computer's data will be used.
